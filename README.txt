席替えツール v1.4.1

主な機能
・名簿を1行1名で入力
・人数に応じた列数と行数の自動計算
・横の列数の手動指定
・前方指定（前から何行目まで）
・ブロック指定（前後左右斜めの周囲8席を禁止）
・隣指定（同じ行の左右に必ず配置）
・条件を満たすランダム座席表の作成
・入力内容と条件の端末内自動保存

iPadでの使い方
1. index.html、style.css、script.jsを同じフォルダに置きます。
2. GitHub Pagesへ3ファイルをアップロードします。
3. 公開URLをSafariで開きます。

注意
・同姓同名を区別する場合は「山田A」「山田B」のように入力してください。
・隣指定では、同じ人を複数の組に登録できません。
・条件が厳しすぎる場合は、列数または条件を変更してください。


v1.1.0 修正内容
・隣条件で2人を選択したまま「追加」を押し忘れても、席替え実行時に自動登録
・前列指定とブロック指定も、選択中の条件を実行時に自動登録
・作成後に全条件を再検証し、条件違反があれば結果を表示しない
・前からの位置表記を「列」に統一


v1.2.0 修正内容
・CSSとJavaScriptに?v=120を付け、GitHub Pages・Safariの旧キャッシュを回避
・画面上部にv1.2.0を表示し、更新成功を目視確認可能に変更
・席替え成功メッセージに、実際に適用した隣指定の2人を表示
・旧版の端末保存データを分離し、古い条件状態の混入を防止


v1.3.0 修正内容
・名簿変更後の古い座席表を自動破棄
・名簿人数と配置人数を照合
・未配置、名簿外、重複配置を結果表示前に検出
・成功時に配置人数を表示
・8列表示を可変幅化


v1.4.0 追加内容
・座席を2つ順番にタップして、人同士を入れ替え可能
・人がいる席と空席をタップして移動可能
・最初に選択した席をオレンジ色で表示
・同じ席を再タップすると選択解除
・「キャッシュ削除」ボタンを追加
・キャッシュ削除時はCache StorageとService Workerを削除し、最新版を再読込
・キャッシュ削除では名簿・条件の保存データを消さない


v1.4.1 変更内容
・名簿、列数、前列指定、ブロック指定、隣指定をブラウザへ保存しない仕様に変更
・ページを閉じて開き直した場合は、以前の入力内容を表示しない
・過去バージョンで保存された席替えツールの端末内データも起動時に削除
・同じページを開いている間だけ入力内容と座席結果を保持
