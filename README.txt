席替えツール v1.3.0

主な機能
・名簿を1行1名で入力
・人数に応じた列数と行数の自動計算
・横の列数の手動指定
・前方指定（前から何行目まで）
・ブロック指定（前後左右斜めの周囲8席を禁止）
・隣指定（同じ行の左右に必ず配置）
・条件を満たすランダム座席表の作成
・入力内容と条件の端末内自動保存

iPadでの使い方
1. index.html、style.css、script.jsを同じフォルダに置きます。
2. GitHub Pagesへ3ファイルをアップロードします。
3. 公開URLをSafariで開きます。

注意
・同姓同名を区別する場合は「山田A」「山田B」のように入力してください。
・隣指定では、同じ人を複数の組に登録できません。
・条件が厳しすぎる場合は、列数または条件を変更してください。


v1.1.0 修正内容
